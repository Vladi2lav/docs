# Учёт времени педагога (Форма Приказ №130)

**Вход:** график учебного процесса (xlsx) + расписание занятий (xlsx) + расписание практики (docx, необязательно).
**Выход:** Word-ведомость учёта учебного времени педагога — по странице на месяц.

Запуск: `start.bat` → http://localhost:8080 (нужен Python или PowerShell; сервер `serve.py` отдаёт файлы без кэша, чтобы браузер не смешивал старые модули с новыми). Библиотеки SheetJS и JSZip подключаются с CDN.

## Как считаются часы

| Что | Откуда |
|---|---|
| Даты недель, чётность (левая/правая), каникулы, практика группы | график: пустая ячейка недели = теория, любой код = нет теории (`К` — каникулы) |
| Пары по дням недели, преподаватель, группа, неделя (обе / левая / правая) | расписание: объединённая ячейка = каждая неделя |
| Индекс и полное название модуля | выбирается вручную из «Обозначений» графика (в расписании не указано) |
| Часы практики по датам, руководитель, группа, модуль | docx практики; без него практику добавляете вручную |
| Колледж, зам. директора, список специальностей | график |
| Праздники и переносы | `data/holidays-kz.json` + свои дни в интерфейсе |
| Полное ФИО, специальность (если не одна в графике / docx практики), план часов | вводятся вручную |

**«Заполнить по документам»** — над каждой дисциплиной и общая кнопка в блоке 2: заполняет всё, что есть в документах, и перечисляет, чего не хватило и где это взять.
**Состояние** нигде не сохраняется: обновили страницу — всё с чистого листа.

**Семестры** определяются графиком: 1-й — до месяца зимних каникул (период «К» у групп педагога), 2-й — сразу после них.
**Принцип: ничего не угадывается.** Поле заполняется, только если оно прямо указано в документе; иначе остаётся пустым и попадает в список «Не хватает».
**Практика:** добавляется сама только из docx, где руководитель назван прямо; вручную — кнопкой «+ Практика по графику» (модуль выбираете вы, периоды — недели графика с его кодом, часы в день вводите сами). Загруженный docx практики применяется всегда: даты своего года — как есть; документ другого года — с предупреждением, часы по дням (6/8 ч, суббота) переносятся на период практики из графика, праздники берутся из календаря.
**Календарь:** вкладка «Календарь рабочих дней» — праздники из `data/holidays-kz.json`, клик по дню и «Перенос дня» (с даты на дату).
**Отработки:** «занятие за дату → проведено в дату»; занятия, выпавшие на праздник, предлагаются списком.

Пара = 2 часа (`HOURS_PER_PAIR`). План часов вводится вручную; пока он пуст, колонки «Запланировано» и «Остаток» в Word пустые.

## Структура

```
index.html            страница (4 шага)
css/style.css
data/holidays-kz.json праздники РК
src/
  config.js           константы и тексты формы
  main.js             состояние и обработчики интерфейса
  parsers/            graph.js · schedule.js · practice.js · timesheet-docx.js   (файл → данные)
  domain/             rows.js (строки ведомости) · calendar.js · timesheet.js (расчёт по дням/месяцам)
  export/             docx.js (Word) · docx-package.js (служебные части пакета)
  ui/                 preview.js (ведомость) · graph-view.js (вкладка графика) · calendar-view.js (вкладка календаря)
  util/               dates · sheet (чтение xlsx)
tests/pipeline.test.mjs  сквозная проверка на файлах из исходники/  (npm install && npm test)
_legacy/              прежняя версия — можно удалить
```

Добавить новый вид документа на выходе — новый модуль в `export/`, принимающий `sheets` из `buildTimesheet`.
Добавить новый источник — новый парсер в `parsers/`, возвращающий простой объект.
